# Python dependencies of the wiki runtime, pinned by version.
#
# docfilter.py and wiki-sync.py import yaml to read exclude_docs / not_in_nav
# from a consumer's mkdocs.yml. That is the only third-party import in the
# runtime, and the job installs this file only after `python3 -c 'import yaml'`
# has already failed, so a host or image carrying python3-pyyaml fetches
# nothing.
#
# Install exactly as the component does:
#   pip install --user -r requirements.txt
#
# Until 1.1.0 this file also carried sha256 hashes and the job installed it with
# --require-hashes. The hashes were the source distribution and the two CPython
# 3.12 manylinux wheels, which is every artefact the digest-pinned python:3.12
# execution image could resolve. On a shell executor the interpreter is whatever
# the host has -- EL9 ships 3.9 -- and pip resolves the wheel built for it,
# which is not in that set, so --require-hashes failed on exactly the air-gapped
# hosts it was meant to protect. A version pin holds on every interpreter; the
# artefact's provenance comes from the index the estate points PIP_INDEX_URL at.
pyyaml==6.0.2
